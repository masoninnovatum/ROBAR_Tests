- **LC.161207.F.1.2** A module called 'Label Control' will be available on the Innovatum Web Menu.

The status of the job will be displayed in the Status column. This grid will display first 500 records submitted to the action and any records with errors will be displayed at the top.

- **LC.161207.F.1.26** Users will be allowed to load saved search filters by click on the Load Filter. Clicking on the Load Filter button display a dialog which contains a list of all available filters, load and cancel buttons. Users will click on a filter and select the Load button to use the search filter. Clicking the Cancel button will close the dialog without loading the filters.
- **LC.161207.F.1.27** The system will allow the user to sort the results by a selected column.
- **LC.161207.F.1.28** Each time the Label Control page loads, any previously set search criteria and /or filters will be loaded and results will be retrieved.
- **LC.161207.F.1.29** If a template associated with the item changes after label control record is created, the system will auto change the Template Name column in the Label Control table to match the Template associated with the Item Number, Label Type, Version record in the Items table. This auto change will occur when the user performs the Update Versions row level action or Mass Update Versions bulk action on the label control record.
- **LC.161207.F.1.3** Only users with the 'LC_View_LabelControl' security privilege enabled will be allowed to access the Label Control module. The 'Label Control' module icon will not be displayed to users without the security enabled.
- **LC.161207.F.1.30** Row level and bulk actions on the Label Control page will be disabled for users who do not have the appropriate security process to access the actions. If a row level action or bulk action is disabled because user does not have authorization, a tool tip will be displayed with the message "User not authorized to perform action"
- **LC.161207.F.1.31** Users will not be able to access a bulk action in Label Control that they don't have security permissions for. Therefore, they will not have the ability to electronically sign for a Label Control bulk action for which they do not have the appropriate security process assigned. If a user attempts to use a bulk action in Label Control without the proper security process, a tool tip will display when user hovers over the bulk action and will display "Not authorized for this action, 'SecurityProcessName'" error message.

Users will be allowed to organize the two columns in the label control records grid.

- **LC.161207.F.1.34** "Label Control" link will be provided on every Label Control Job Details page, which will allow users to access the main label control page,
- **LC.161207.F.1.35** The bulk actions for the Label Control module will be developed using plugin architecture. They will be developed such that each plugin can be modified, installed and uninstalled independently without impacting other Label Control or Innovatum Web Menu functionality.

For an LCN record where LC – MasterDataVersion is not NULL the information tied to the specific Master Data Version will be displayed. (Note: The value ‘N/A’ should not be saved to the database, it is for display purpose only)

Matching label master record not found." will be displayed on the Job Details page.

- **LC.161207.F.16.8** When label control records are submitted to the Link to Label Master bulk action and the "Use Latest If No Exact Match" is checked, if the action does not find a label master that exactly matches the label control or there is no latest label master, the record will be ignored and an error message "Could not link to master. Matching or latest label master record not found." will be displayed on the Job Details page.
