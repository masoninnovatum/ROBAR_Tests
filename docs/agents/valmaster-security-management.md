## Security (Designer-era FRS-6.1.x)
- **URS-6.1.4** enforce password policy; **FRS-6.1.4.1** password changes at set intervals; **FRS-6.1.4.2** Active Directory authentication (settings ADAuthentication, ADDomain, per-user "Authenticate Against Active Directory" with the Setup1-3 matrix); **FRS-6.1.4.3** minimum length + letters + numbers per settings; **FRS-6.1.4.4** lock-out after a number of failed logins; **FRS-6.1.4.5** no password reuse for X days. **URS-6.1.6 / FRS-6.1.6.1** unauthorized login attempts monitored; all invalid logins saved in the system audit log.
