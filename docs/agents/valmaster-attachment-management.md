# ValMaster requirements - Attachment Management / Attachment Upload (modules "Attachment Management" 52 rows, "Attachment Upload" 48 rows; Customer Specific blank, not Obsolete; pulled 2026-10-11; condensed, message strings verbatim)

## Attachment Management (AT.170103.*, SNT.170330.*)
- **U.1** File Purpose security governs users; **U.2** users customize File Purpose entries; **U.12** link a previously uploaded attachment to a Label Control Number, Item Number or Template; **U.13** job status when done; **U.16** view documents in the page; **U.19** download attachments; **SNT.170330.U.6** choose a version when several exist.
- **F.1.1** every row of the upload grid has a File Purpose drop-down; **F.1.2** default File Purposes: Approvals, IFU, Label Requests; **F.1.3 / F.1.4** the list comes from the Codes table, Code Type "File Purpose"; **F.1.5** default File Purposes have coordinating Link, View and Download security processes; **F.1.6 / F.1.7** without `FP_xxxxx_View` / `FP_xxxxx_Download` the View / Download actions are disabled on Link Management / Attachment Management; **F.1.8** linking without `FP_xxxx_Link` -> Job Detail error "Error: FP_xxxx_Link security not enabled."
- **F.2.1** new FP_ processes are generated when a File Purpose code is entered; **F.2.3 / F.2.4 / F.2.5** `FP_xxxx_Link`, `FP_xxxx_View`, `FP_xxxx_Download` processes.
- **F.12.1** page reachable from an icon on the web menu; **F.12.2** MenuCaption "Attachment Management"; **F.12.3** SecurityProcess `AM_Attachment_Management`; **F.12.4** MenuParent "Document Control"; **F.12.5** remove / add filters; **F.12.7** Retrieve Data button; **F.12.8** grid of results; **F.12.9** columns of the AttachmentFiles table; **F.12.10** Advanced Options with Available Fields / Selected Fields lists and a Limit Results box; **F.12.11** multi-select check boxes for linking; **F.12.12** row Actions: View, Download; **F.12.13** "No records to view"; **F.12.14** page counter + rows-per-page drop-down; **F.12.15** "View x-x of x" counter bottom right; **F.12.16** "Linking to x Label Control Numbers" count when called from Label Control; **F.12.17** Link button performs the association; **F.12.18 / F.12.19** called from Label Control via Bulk Action "Link Attachments" with the Job ID; **F.12.20** opened from the web menu icon, the Link button is DISABLED; **F.12.21** Actions > "Edit Attributes" popup to edit File Purpose, Attachment Group, Param1, Param2.
- **F.13.1** after a link job an "Attachment Management Job Detail" page with the status; **F.13.2** grid of the data being linked; **F.13.3** Status column "Completed" or "Error"; **F.13.4** "Job completed successfully"; **F.13.5** "Job completed with errors"; **F.13.6** duplicate link -> "Error: Link already exists."
- **F.16.1 - F.16.3** View action: downloaded to the local machine and opened in the browser, else the default application. **F.19.1 - F.19.5** Download action: needs the File Purpose download security, disabled otherwise, options to download, Windows save dialog.
- **SNT.170330.F.6.1 - 6.8** version popup when several versions exist: lists all versions with multi-select check boxes next to Version, Last Touch, Last User; the chosen versions are viewed / downloaded; Submit performs the action; Cancel closes the popup and returns to the home screen; no popup for a single version or when editing; selecting the Edit action writes an ACTIVITY record with Action = Edit.

## Attachment Upload (AU.170103.*)
- **U.1** upload documents into the ROBAR database; **U.2** only users with the proper security get the menu option; **U.3** single file uploads in one transaction; **U.4** define a file purpose; **U.5** define parameters.
- **F.1.1 / F.1.2** new web menu module "Attachment Upload", MenuParent "Document Control"; **F.1.3** table AttachmentFiles (FileID, Sequence, LastTouch, LastUser, FilePurpose, Description, AttachmentGroup, Filename, Param1, Param2, Blob, FileExtension, OriginallyUploadedBy, UploadedOn, Active(Y,N), Id); **F.1.4** Active defaults to Y; **F.1.5** global setting `AttachUploadExcludedExt` blocks extensions with the message "File extension not allowed."; **F.1.6** default excluded list .EXE, .DLL, .CHM, .SQL, .COM.
- **F.2.1 - F.2.3** security process `Attach_Upload_View`, enabled in MenuWebIntegration and in the Security table.
- **F.3.1** Browse button; **F.3.2** popup to select a file; **F.3.3** grid columns FilePurpose, FileName, Description, Param1, Param2; **F.3.4** FileName copied into Description; **F.3.5** Description editable; **F.3.6** tabbing / clicking into Description selects the whole field; **F.3.7** a FileID per document; **F.3.8** each record has a pre-selected check box (uploaded on "Upload Attachments"); **F.3.9** the check box can be cleared; **F.3.10** Reset button clears the grid; **F.3.11** text field "Attachment Group" for the batch; **F.3.12** failures: "Job completed with errors - the following files were not uploaded:" + the list; **F.3.13** uploaded files get Sequence 0; **F.3.14** success: "X files uploaded successfully" under the page title.
- **F.4.1 / F.4.2** File Purpose drop-down per row, configurable in the Codes table; **F.4.3** predefined list Label Requests, Approvals, IFU (**F.4.7**: Approvals, IFU, Label Requests, Redline, Redline Compare); **F.4.4** drop-down shows "Select Purpose" first; **F.4.5** upload with a missing File Purpose -> Upload button disabled, tooltip "Missing File Purpose"; **F.4.6** choosing a File Purpose with records selected -> popup "Apply to all records?" Yes / No radio buttons + "do not show again" check box (applies to the current selection only, active again after submit / reset); **F.4.8** default File Purposes have coordinating Edit security process entries.
- **F.5.1** Param1 / Param2 editable; **F.5.2 / F.5.3** entering Param1 / Param2 with records selected -> "Apply to all records?" popup with Yes / No and "do not show again".
