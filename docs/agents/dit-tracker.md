# DIT Tracker — Defects Found During QA Work

Running log of confirmed product defects surfaced during QA work in this repo or the sibling
`ROBAR_Tests` repo (formal test script review/execution, exploratory testing, or AI-assisted test
generation) — kept so a finding doesn't get lost between being discovered and actually being filed
as a DIT (Development Issue Tracking) ticket.

**Maintenance convention:** whenever a QA session (this repo or `ROBAR_Tests`) confirms a real
product defect — not a test-script wording issue, not an environment quirk — add a row here. Once
it's filed as an actual DIT ticket, fill in the DIT# and update Status. This is a distilled tracker,
not a full repro writeup — link to the source doc (module reference section, exploratory session
log, or test-generation doc) for full detail rather than duplicating it here.
