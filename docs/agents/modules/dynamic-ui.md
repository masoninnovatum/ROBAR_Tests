### Dynamic UI vs ValMaster (DUI.20190822.*, `valmaster-dynamic-ui.md`) — re-check 2026-10-09 (`tests/Cross-Module/Dynamic_UI_Requirements.spec.ts`, headless, 1 clean run)
- **OK, no deviations:** for six pages (Facility Management, Global Settings Management, Print Config Management, Printer Control, Label Type Management, Lot Management) the admin user's Add icon / Edit / Delete (needs a selected row) / Excel Import / Excel Export / Audit follow the shipped `DynamicUIHeaderDefaultRecords.cs` exactly (Global Settings: no Delete, no Excel Import; Print Config: no Add (icon not rendered), no Delete, no Excel Import; Facility / Printer Control: everything); a user without the CanView process (MB group with only Login_WebMenu) gets **"User is not authorized to view this page"** on all six pages opened by URL (`/InnoPages/DynamicUI/DynamicUI?Heading=...&Definition=...`) (F.3.2).
