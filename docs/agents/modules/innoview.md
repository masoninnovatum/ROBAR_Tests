## InnoView second pass - Playwright-confirmed 2026-11-03 (`tests/Cross-Module/InnoView_Search_Export_Security.spec.ts`, headless; the first pass specs are above)
- **Report pages open by URL** as a top-level page in the web-menu session: `http://<server>/Innovatum/innoview/Screens/ViewReport.aspx?ReportName=<name>` (menu: `.../Screens/MainMenu.aspx`). Prompts are the page's selects / text inputs IN ORDER (Login History: User select, Workstation select, Start Date, End Date; Activity History: User, Workstation, Action (115 actions on TST703, first one "- PrintRequest Rejected"), dates; Label Changes: Label Type select, Label Name text); the date prompts are READ-ONLY jQuery datepickers (set `input.value` by script, then Submit); defaults = today. Buttons are `input[type=submit]` Submit / Export. Result table `[id$=rptTable_tblMain]` (all rows on one page, no paging: Login History for Claude01 since 2024 = 4465 rows), headers Logged / User ID / Workstation / Time Zone / Full Name / Action / Object Type / Object Name / Object Version / Reason Code / Comments / Signature / Sequence Number / Rowguid. `ViewReport.aspx?ReportName=Search+Items+By+Item+Number` opened directly = IIS Runtime Error (the other reports open fine).
- **Values work:** User = Claude01 returns only that user; Start = End = today returns a subset all dated today; Action filter returns only that action; Label Changes by Label Type returns the label's change rows (22 columns).
- **Export (IVFRS-3.3.1):** the Export button POSTs and the page registers `window.open('<web>/temp/<Caption_with_underscores>_<yyyyMMdd>_<HHmmss>.xlsx')` in `[id$=divJavascript]`; the file has the same rows in the same order as the table, header = raw column names (`UserID`, `TimeZone`, `rowguid`). **The file is downloadable without a session (HTTP 200)** - tracker row.
- **Security is menu-only:** `ViewReport.aspx.cs` only calls `RedirectIfNotLoggedIn()` and builds `new Report(name)` from the query string, so a user without Login_InnoView / Innov_ViewPrintHist (fixture CLPROp01) still gets the View Print History prompts and results by URL. The tile and category visibility specs (first pass) remain valid for the menu.
- **Menu:** the category title click expands the category (collapsed at the start) and a second click collapses it again (IVFRS-2.1 collapsible menus met); no Help link on InnoView pages (IVFRS-2.1). Test data: none created; one export file stays in the server temp folder.
